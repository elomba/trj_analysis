# GPU dynamics overflow regression

`run.nc` is a 5.8 MB, 256-particle, 700-frame LAMMPS-style NetCDF fixture generated by `generate.py`. Its independent positions and velocities provide many time origins; the final Q shell makes the former integer normalization product exceed 2^31−1.

Load the same NVHPC and NetCDF modules used to build `trj_analysis`, then run `bash run.sh /absolute/path/to/trj_analysis`. The script generates the fixture, runs the binary in `work/`, and exits nonzero unless Fs(Q,0), F(Q,0)/S_NN(Q), and both longitudinal currents pass their zero-time checks. `check.py` also prints a finite-difference curvature diagnostic.

On the cluster, submit `sbatch run_slurm.sh`. The job has a 10-minute limit.
